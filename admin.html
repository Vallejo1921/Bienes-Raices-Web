Publicación segura

GitHub Pages sólo entrega archivos estáticos: no existe un administrador global ni un backend que valide escrituras. Por eso este editor no pide contraseñas, tokens ni PAT, y no guarda nada en el servidor. Para publicar, revisa el JSON exportado, reemplaza data/properties.json, ejecuta las pruebas y el build, y haz commit/push. El cambio es global únicamente después del despliegue. La guía completa está en DEPLOY_GITHUB.md.
